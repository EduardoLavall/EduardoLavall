## Featured projects

### 🧱 [Minecraft RPG Crossplay Server](https://github.com/EduardoLavall/minecraft-rpg-crossplay-server)

A versioned and reproducible **Minecraft Survival/RPG server ecosystem** with Java + Bedrock crossplay.

The project includes a local Server Control Center, safe plugin/server installation, live console, configuration management and the foundations for a future integrated web platform.

**Highlights:** Paper • Java + Bedrock • Geyser/Floodgate • Python tooling • Server Control Center • Web platform architecture

---

### 🪙 [GranaXP](https://github.com/EduardoLavall/GranaXP)

A gamified personal finance MVP where financial management becomes a game loop with **quests, XP, coins and upgrades**.

It includes an interactive presentation and a playable browser demo, working fully offline without a backend.

**Stack:** HTML • CSS • JavaScript • SVG • Browser APIs • Gamification

---

### 📄 [compressorPDF](https://github.com/EduardoLavall/compressorPDF)

API created around a real business problem: processing and compressing PDF files to significantly reduce storage and transfer overhead.

The project supports HTML-to-PDF generation, compression with Ghostscript and a Docker-based setup.

**Stack:** Python • Flask • Docker • Ghostscript • REST API

---

### 🎮 [Scopophobia](https://github.com/EduardoLavall/Scopophobia)

A game project built around the theme of social anxiety, exploring how an emotional subject can be represented through gameplay.

Game development is a parallel area where I experiment with prototypes, mechanics and interactive experiences.
